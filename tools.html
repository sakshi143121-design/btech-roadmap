Start Year 1

Free tools for every B.Tech student

The websites and apps that help you write code, practice, learn and show your work. All of them have a free version.

You do not need all of them. Start with VS Code, GitHub and LeetCode. Add the others only when you need them.

Write and run code

VS CodeA free code editor. This is where you write your code. OnlineGDBRun C, C++, Java and Python in your browser, with nothing to install. GitHubSave your code online and show your projects to the world.

Practice problems

LeetCodeInterview-style problems. Start with the Easy ones. HackerRankFriendly practice and skill tests for beginners. GeeksforGeeksClear explanations and practice, very useful before exams. CodeforcesCoding contests. A good challenge once you are comfortable.

Learn and look things up

MDN Web DocsThe best reference for HTML, CSS and JavaScript. W3SchoolsShort, simple examples that are easy for beginners. freeCodeCampFree courses and exercises, with certificates. Stack OverflowQuestions and answers for when you are stuck on an error.

Build and show your work

GitHub PagesPublish a website for free from your GitHub. NetlifyPublish your website for free by dragging in your folder. CanvaMake banners, thumbnails and posters for your content. LinkedInYour online resume. Companies and recruiters look here.

Which tool in which year?

  • Year 1: VS Code and OnlineGDB
  • Year 2: GitHub and LeetCode
  • Year 3: Netlify or GitHub Pages, and LinkedIn
  • Year 4: LeetCode for revision, and LinkedIn for applying

Websites can change their free plans, so check each one before you rely on it.
