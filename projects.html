Projects that build your skills

Project ideas for every year, from your first program to your final-year project, with what you learn from each one.

Why projects matter: they prove you can build, not just study. A small project that you finish is better than a big project that you never complete.

Project ideas by level

Tap a level to open it.

Beginner projects (Year 1)
  • Calculator: add, subtract, multiply and divide numbers given by the user. You learn: input and output, operators, if-else.
  • Number guessing game: the computer picks a number and you try to guess it. You learn: loops and random numbers.
  • To-do list: add tasks and show them on screen. You learn: arrays or lists, functions.
  • Personal web page: a page about you, your skills and contact details. You learn: HTML and CSS.
Core projects (Year 2)
  • Tic tac toe: two players, with a check for the winner. You learn: 2D arrays, functions, game logic.
  • Quiz website: questions, answers and a final score. You learn: JavaScript and handling clicks.
  • Student management app: add, search and delete student records. You learn: OOP, files or SQL, and the basic add, read, update, delete pattern.
  • Portfolio website, live online: your projects on one page, published for free. You learn: Git, GitHub and publishing a site.
Advanced projects (Year 3)
  • Website with login: sign up, log in, and save each person's data. You learn: frontend, backend, databases and basic security.
  • A tool for your college: for example a notes sharing site, a timetable viewer or an event board. You learn: understanding real users and planning features.
  • Data or AI mini project: use a public dataset to predict or sort something. You learn: Python, data cleaning and basic machine learning.
  • Open source fix: fix a small bug or improve the documentation of a public project. You learn: reading other people's code and sending a pull request.
Final-year projects (Year 4)
  • Final-year project: choose a real problem and build a complete solution. You learn: planning, teamwork and testing.
  • Project with real users: ask 10 people to try it and write down their feedback. You learn: improving a product from feedback.
  • Live project with a demo video: publish it online and record a 2-minute video. You learn: publishing and explaining your work, which interviewers love.

How to build any project, step by step

  1. Pick a small idea you care about.
  2. Write 3 to 5 features on paper.
  3. Build the smallest working version first.
  4. Test it with a friend and fix the problems.
  5. Upload it to GitHub with a good README.
  6. Improve it, one feature at a time.

A good README has 5 things

  • What the project does, in 2 lines
  • A screenshot
  • How to run it
  • The technologies you used
  • Your name and contact link

Mistakes to avoid

  • Copying a full project from a video without understanding it. If you follow a tutorial, add 2 features of your own so it becomes yours.
  • Choosing an idea that is too big. Start small, then grow it.
  • Never finishing. Finish a simple version, then improve it.
  • Keeping it on your laptop. Upload it, so others can see it.
